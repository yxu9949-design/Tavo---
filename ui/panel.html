第四面墙
设置

仅对「角色本人」模式生效。角色起初不知道第四面墙和现实玩家的身份，认识会随着你们的交流逐渐形成。

分析会额外调用一次当前模型。不会自动跳阶段或强制角色接受某种解释。

只保存当前人物、当前模式和当前记录的独立记忆，不修改 Tavo 原本的长期记忆。可以手动编辑或使用当前模型总结旧对话。

当前模式的专用提示词：开场、身份协议、收尾。两种模式分别保存，不影响 GodOfNovel 或其他预设。

可用占位符：{{CHAR_NAME}}、{{USER_NAME}}、{{USER_INPUT}}。

TavoJS 目前不提供真正的流式 token 回调，回复会在请求完成后整体显示。自动吐槽和自动总结默认关闭，以避免产生额外 API 费用。

在这里编辑或删除独立私聊消息。不会修改主线。
