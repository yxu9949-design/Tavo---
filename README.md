# Tavo 第四面墙 · 角色直聊

> 非官方 Tavo 社区插件，适用于单角色卡与多人角色卡。通过独立会客厅进行剧情之外的皮下语 C 交流，同时支持人物选择和历史记忆。

## 功能定位（v1.3.1）

这里采用 **“负责扮演该角色的语 C 搭档 / 中之人”** 的皮下交流方式：

- 主线是共同创作的剧本，皮下聊天发生在剧本外；
- 可以聊主线发生过的事件、吐槽彼此演绎，也可以聊无关日常；
- 玩家现实身份与故事中的代入人物明确分开；
- 人物选择器决定“正在与哪一位人物的扮演搭档私聊”，不是把不同角色混成一人；
- 默认采用自然、简短、社交软件式的聊天语气，不再被 GodOfNovel 的长篇小说格式绑架。

### 功能

| 项目 | v1.3.1 |
|---|---|
| **角色识别** | 从当前卡片/多人卡标题与可用章节抬头推断角色，手动下拉选择 |
| **单窗口** | 只有一个第四面墙窗口，内部可切换不同人物与不同私聊记录 |
| **读取主线** | 直接使用 TavoJS 读取当前会话消息与可访问的长期记忆；默认附带最近20层，兼顾更早相关片段 |
| **皮下记忆** | 独立于原 Tavo 长期记忆，支持手动编辑、清空、模型总结旧私聊；按人物/记录分开 |
| **记录管理** | 新建、重命名、删除记录；编辑、删除单条私聊消息；清空私聊、重新回答 |
| **可编辑提示词** | 开场、身份协议、收尾三部分，支持恢复默认 |
| **时间感知** | 发送时间与距离上次 AI 回复的时间间隔，作为皮下历史提供给模型 |
| **吐槽主线** | 手动对最新一条主线 AI 回复发表评论；可在设置中选开启用实时吐槽并设置概率 |
| **图片与语音** | 可选模拟图片 \`[img: ...]\` 与 \`[voice:emotion:内容]\` 协议，按需调用当前生图/TTS API |
| **数据迁移** | 尝试从旧版 \`fourthwall_direct_v11.json\` 迁移聊天记录，原旧数据不删除 |
| **主线安全** | 不会修改 Tavo 主线、角色卡、世界书、正则和原长期记忆 |

## 安装

1. 下载 [最新版安装包 (.tpg)](dist/tavo-fourthwall-v1.3.1.tpg)。
2. Tavo → 设置 → 插件 → 安装 → 选择文件。若已有旧版，先关闭旧版，再升级至同一插件 ID。
3. 打开已有角色卡聊天、开启高级渲染，点击紫色 **Ⅳ**。
4. 选择人物，进入 **私聊**。可通过“＋新记录”管理不同皮下话题。
5. **皮下记忆**中可以编辑或总结私聊；**提示词**中可自行修改皮下身份协议；**设置**中可以调节主线层数与其他能力。

## 运行方式与限制

- **皮下交流方式**：与负责演绎人物的语 C 搭档私聊，不是角色本人觉醒或主线续写。
- **附加人物选择器**：同一张多人卡中可以明确选择哪位人物的扮演搭档。
- **TavoJS 的生成接口仅返回完整文本，不支持流式 token 回调**，所以回复会整体显示而非逐字生成。
- 本插件使用 Tavo 公开 API。实时吐槽采用可关闭的页面轮询，仅会客厅打开时检查，触发会产生额外 API 费用。
- 皮下总结使用当前模型 API；不保证每次总结或角色识别都绝对准确。
- 界面、存储与业务逻辑基于 Tavo 插件环境独立实现，不保证与其他客户端插件的界面完全一致。

## 隐私与存储

私聊保存在当前聊天的 \`fourthwall_backstage_v2.json\` 文件中；原有旧记录仍保留供回滚。删消息、删记录、清空记忆只影响会客厅存储。主线消息及原 Tavo 记忆均为只读。调用模型时会发送必要的选中人物设定、主线片段、长记忆与皮下记录给当前聊天配置的模型供应商。生图和语音需要当前聊天已正确绑定对应服务。

## 质量与限制

已进行源码语法与安装包结构检查，但**尚未在用户的实际 Tavo iOS 环境中完成安装和模型端侧验证**。建议先在备份聊天中测试；发现问题可提交 GitHub Issue。
