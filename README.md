# Tavo 第四面墙

非官方 Tavo 社区插件，支持单角色和多人角色卡。在同一个窗口自动识别人物，由玩家手动选择交流对象。

## v1.5.0：极简手机界面

聊天页面只保留：
- **第四面墙**（标题）
- **← 关闭** 与 **⚙ 设置**
- 聊天内容、输入框、发送按钮

其他控件全部收进 **⚙ 设置**，包括人物与模式、聊天记录、消息编辑删除、重新回答、主线同步与吐槽、独立记忆、角色认知档案、提示词及高级配置。

在角色本人模式中，角色**最初不知道第四面墙与现实玩家身份**，不再默认知道自己是虚构人物。角色在私聊中可以逐步理解这些概念；认知状态与角色本人独立保存。「设置 → 认知」可以手动纠正、重置，或调用一次模型分析近期对话（可能产生额外费用）。不会强制接受世界观解释。

## 两种交流模式

在「⚙ 设置」中的「交流模式」中切换：

| 模式 | 你在与谁交流 | 体验 |
|---|---|---|
| **角色本人直聊** | 角色本人 | 保持人物原本性格与历史记忆，角色明确知道正与故事外的玩家交流，可以讨论经历而不推动主线 |
| **皮下语 C 搭档** | 负责演绎选中人物的幕后搭档 | 将主线视为共同创作的剧本，可以聊演绎、剧情安排和日常，而不假装自己是小说人物 |

上述双身份切换是 Tavo 版增加的功能。备份包中的 LittleWhiteBox「四次元壁」源码主要提供皮下语 C 私聊及可选的实时吐槽，不包含这两种身份之间的原生切换控件。

**模式互相隔离**：每位人物的角色本人／皮下搭档分别保存会话、聊天、独立记忆和提示词。旧版皮下聊天保留在皮下模式，不自动转为角色本人。

## 功能

- 读取当前 Tavo 聊天和可访问的长期记忆；识别多人物卡并手动选择人物
- 单窗口与多份独立聊天记录、编辑删除消息、清空、重新回答
- 当前模式独立记忆、可选自动总结、可编辑提示词
- 手动或可选自动主线吐槽，可选模拟图片与语音
- 原有主线、世界书与原始长期记忆不被会客厅修改

## 安装

1. 下载 [v1.5.0 安装包](dist/tavo-fourthwall-v1.5.0.tpg)。
2. Tavo → 设置 → 插件 → 导入安装包并启用。使用旧版时建议先停用旧版，避免重复挂载。
3. 打开已有角色卡聊天，启用高级渲染，点击紫色「Ⅳ」按钮。
4. 点击「⚙ 设置」选择人物和模式，然后点「← 返回聊天」。认知、独立记忆和提示词均在设置内。

## 技术与限制

数据存储在当前聊天作用域的 fourthwall_backstage_v2.json，读取主线时会将相关片段和记忆发送给当前模型供应商。
TavoJS 生成接口暂不提供可用于此插件的流式 token 回调，因此回复会整体呈现。
这是一套独立的 Tavo 适配实现，不重新分发 LittleWhiteBox 的界面源码。

目前已通过 JSON、JavaScript 和模拟 Tavo API 的基础测试，但**尚未在真实 iOS Tavo 客户端中验证新版安装与模型回复**。建议先使用备份聊天测试。

参考：[Tavo 插件开发](https://docs.tavoai.dev/cn/guides/plugin-development/) · [TavoJS API](https://docs.tavoai.dev/cn/guides/javascript-api/)。
