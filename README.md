# Tavo 第四面墙 · 角色直聊

一款适用于 **Tavo 角色卡聊天**的非官方社区插件。面向单角色卡和多人角色卡，不限作品、题材或特定人物。

通过独立会客厅，让角色暂时脱离原本的剧情叙事，直接与屏幕外的玩家交流。角色可以参考当前 Tavo 聊天中已保存的 AI 回复与可读取的长期记忆，谈论故事里已经发生的事情，同时保留原有性格、关系和表达习惯。

> **插件不会修改原始角色卡、主线聊天、世界书或长期记忆。** 这是独立的直聊功能，并非让故事自动续写。

## 功能简介

- **直接读取当前聊天**：从 Tavo 当前会话读取可访问的 AI 回复、用户输入和长期记忆，按问题检索相关历史。
- **识别单人及多人卡**：从角色卡信息及可用聊天文本尝试识别角色，统一在一个窗口内通过下拉菜单选择交流对象。
- **第四面墙直聊**：明确区分现实玩家与玩家在角色卡剧情中的代入身份，不把会客厅当作主线剧情现场。
- **独立聊天记录**：会客厅消息与主线分开存储；支持删除单条直聊消息，或清空当前选中角色的直聊记录。
- **自动清理历史格式**：在检索历史时去除思维链、状态栏等结构性文本，减少它们对直聊的干扰；不会更改原始消息。
- **同步剧情**：主线有新进展后，可以点击「同步剧情」重新读取当前会话。

## 安装与使用

1. 下载 [最新版插件安装包（.tpg）](dist/tavo-fourthwall-v1.2.1.tpg)。
2. 进入 **Tavo → 设置 → 插件 → 安装**，选择该文件并启用；如曾安装旧版，先禁用旧版以免冲突。
3. 根据 Tavo 版本要求，启用**高级渲染与 JS 支持**；打开任意已有的角色卡聊天。
4. 点击聊天内的紫色 **✦** 按钮，打开唯一的第四面墙窗口。
5. 在顶部选择想交流的人物，即可直接提问、讨论历史剧情或角色设定。
6. 如有新剧情，点击 **「同步剧情」**；如需整理会客厅记录，可删除单条消息或清空当前人物的直聊记录。

## 使用说明

**角色的主线身份与现实玩家的身份不同。** 插件会向模型明确说明：此时是在剧情之外进行直接交流，而不是要求角色继续执行主线行动。人物可以回忆自己在故事中的经历，但不应把虚构事件当成现实玩家刚刚实际经历的事情。

历史检索依据当前 Tavo 会话中可访问的数据，不保证能读取未保留的消息或每一种自定义记忆格式。多人物识别采用启发式规则，对特殊格式角色卡可能出现遗漏或误识别；模型是否严格遵循第四面墙规则仍受所用模型影响。

## 删除与隐私

删除和清空操作**仅作用于独立会客厅聊天**，不会删除 Tavo 主线聊天和长期记忆。每次直聊生成会把从聊天及记忆中检索出的相关内容发送给当前聊天配置的模型 API；插件本身不需要额外的外部服务端。
