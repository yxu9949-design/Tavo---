# Tavo 第四面墙 · 角色直聊 v1.2.0

适用于 Tavo 的非官方社区插件。**本版本只修改第四面墙直聊插件，不会删除/修改主线聊天消息、世界书、记忆或原始角色卡。**

## 新功能

- 明确区分：现实里的你（屏幕外的玩家）与小说中的 Raymond（你扮演的故事化身），角色承认正在进行第四面墙聊天，而不是继续演主线。
- 重新编写强约束的直聊预设，提供正误示例，禁止把玩家当成身处伦蒂尼姆的小说人物，也禁止输出小说章节/动作/状态栏。
- 读取 Tavo **当前聊天消息**（AI 回复和用户输入）、长记忆和可用的归档向量，自动检索相关内容。
- 单窗口，自动拆分多人角色卡，并通过角色下拉列表手动选择人物。
- 每条会客厅消息右上角 `×` 可单独删除；“清空”清除当前所选角色的全部会客厅消息。所有删除均需二次确认，操作只作用于 `fourthwall_direct_v11.json`，**不会删除主线和长期记忆**。
- 会客厅沿用旧存储文件，升级后尽量保留旧会客厅聊天。

## 安装

1. 下载 `dist/tavo-fourthwall-v1.2.0.tpg`，在 Tavo 设置 → 插件 → 安装中导入。
2. 若存在旧版，先关闭旧插件后升级；打开高级渲染和 JS 支持。
3. 在主线聊天内点击紫色 `✦`，选择“拉普兰德”或“德克萨斯”，对人物发送“好久不见”。正确回复应承认这是现实玩家在故事之外的问候，不应反驳说“今天早晨我们才见面”。
4. 点击“同步剧情”可重新读取新的主线消息。

## 注意

- **没有完成用户手机上真实 Tavo 端的安装和模型输出验证。** 本地自动化只模拟 TavoJS 对话和文件接口；实际模型是否遵守提示词仍受模型影响。
- 角色自动识别是启发式的，对极不规范的卡名可能需要进一步适配。
- 删除单条会客厅消息或清空当前角色会客厅后不会自动删除相同历史在 Tavo 主线中出现的内容，因为本插件根本不修改主线。
- 生成操作会将检索出的部分剧情和记忆通过当前聊天绑定的模型 API 发送。
